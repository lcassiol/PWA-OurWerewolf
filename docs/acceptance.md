# Acceptance Coverage Audit

Audit date: 2026-11-05

Scope: all 70 Scenarios in the four specs under
`openspec/changes/criar-jogo-lobisomem-web/specs`, checked against the final
production implementation, unit/integration tests, and Playwright E2E suite.

Test runs:

- `npm test` passed 111 tests (server: 26, web: 40, domain: 43, shared: 2).
- `npm run test:e2e` passed Android Chrome's complete six-player flow and the mobile/PWA test on Android Chrome and iOS WebKit (3 passed). The duplicate iOS full-game project is intentionally skipped (1 skipped).
- Playwright launcher cleanup was verified after the run with no listeners remaining on ports 3001 or 4173.
- `npm run smoke:api` was executed successfully against the Docker deployment, covering health, room creation, session restoration, and an authenticated WebSocket snapshot.

This file remains ASCII. HTML character entities preserve the exact rendered
spelling of test names that contain Portuguese accents. No scenario is
classified `Manual` in this final audit.

Status meanings:

- `Covered`: passing automation directly asserts the scenario's material behavior, possibly across domain, server, and UI layers.
- `Partial`: passing automation asserts only part of the scenario; the missing assertion is stated in the row.
- `Manual`: no adequate automated acceptance check exists; the referenced manual procedure is pending and is not claimed as passed.
- `Uncovered`: required production behavior is absent or contradicted, with no valid acceptance path.
